Independent FC — Admin

Connect with a GitHub token that can write to the repo. That unlocks the editors and lets you publish changes straight to the live site.

How to create a token (2 minutes)
  1. Open github.com/settings/personal-access-tokens/new
  2. Token name: ifc-admin · Expiration: your choice
  3. Repository access → Only select repositories → choose IndependentFC
  4. Permissions → Contents: Read and write → Create token
  5. Copy the token and paste it above.

The token is stored only in this browser (localStorage) and is only ever sent to api.github.com. Only use this page on a device you trust.
